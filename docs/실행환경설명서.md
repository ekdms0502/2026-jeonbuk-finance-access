# 실행환경 설명서

팀명: 금방(금융 방방곡곡) · 작품명: 전북 금융 사각지대 진단과 찾아가는 은행 최적 동선 설계 · 분야: 현안 해결 구현

## 1. 실행 환경 요약

| 항목 | 값 |
|---|---|
| 언어 | Python 3.11 이상, JavaScript(ES2020) |
| 검증 환경 | macOS 15 (Apple Silicon), Python 3.14.6, Node.js 26.4.0 |
| 외부 서비스 | 검증 실행에는 불필요. 원본 재수집 시에만 ECOS·카카오 로컬 API |
| 네트워크 | 오프라인 실행 가능 |
| 예상 실행 시간 | `verify_offline.sh` 기준 약 1~3분 |
| 디스크 | 압축 해제 후 약 11MB |

Windows에서는 WSL2 또는 Git Bash를 권장한다. `verify_offline.sh`가 bash 스크립트다.

## 2. 설치 절차

```bash
# 1) 압축 해제 후 폴더로 이동
cd 금방_전북금융사각지대진단과찾아가는은행최적동선설계_코드분석파일

# 2) 가상환경
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate

# 3) 라이브러리
python3 -m pip install -r requirements.txt

# 4) Node.js 20 이상 설치 확인 (별도 패키지 설치 불필요)
node -v
```

## 3. 실행 절차

### 3-1. 전체 검증 (권장, 키 불필요)

```bash
bash verify_offline.sh
```

정상 종료 시 마지막 줄은 `PASS (offline)`이고 종료 코드는 0이다.

### 3-2. 대시보드 열람

```bash
open docs/demo-jeonbuk/index.html          # Windows: start docs\demo-jeonbuk\index.html
```

로컬 서버가 필요 없다. 데이터는 `data.js`·`map-data.js`에 정적으로 들어 있다.
차량 수, 운영일, 1일 최대 방문 수, 장소당 서비스시간, 시작·종료 시각을 바꾸면
최소·기본·확대·사용자 시나리오를 브라우저 안에서 다시 계산한다.
계산 수식과 이론 설명은 `docs/demo-jeonbuk/methodology.html`에 있다.

### 3-3. 개별 단계 재실행

```bash
PYTHONPATH=src python3 src/build_typology.py                        # 취약유형 군집
PYTHONPATH=src python3 src/build_jeonbuk_route_scenario.py --reuse-matrix   # 순회 배정
PYTHONPATH=src python3 src/build_scenario_evidence.py               # 민감도 감사
PYTHONPATH=src python3 src/build_dashboard_data.py                  # 대시보드 번들
PYTHONPATH=src python3 src/validate_outputs.py                      # 무결성 재계산
```

### 3-4. API 키가 필요한 경로 (선택)

ECOS 원본을 새로 받을 때만 필요하다. 검증·심사에는 쓰지 않아도 된다.

```bash
cp .env.example .env
# .env 안의 ECOS_API_KEY 값을 발급받은 키로 교체
./verify.sh
```

`.env`는 `.gitignore`에 등록되어 있고 제출물에도 포함되지 않는다.

### 3-5. 원본 보유 환경 전용 (선택)

`data/raw/`에 원천 스냅샷을 가진 환경에서만 실행한다. 제출물에는 원본이 없으므로
이 스크립트는 실패하는 것이 정상이다.

```bash
bash verify_source_lineage.sh    # 원천 SHA-256, 수집 로그, 행정경계 포함관계 대조
```

## 4. 데이터 경로

- 코드가 읽는 경로는 전부 저장소 루트 기준 **상대경로**다. 절대경로·홈 경로는 쓰지 않는다.
- `data/processed/` — 가공 데이터 28개. 제출물에 전량 포함되어 있어 바로 실행된다.
- `data/raw/` — 원본 공개 데이터. 용량(약 370MB)과 재배포 조건 때문에 제외했다.
  각 원천의 다운로드 URL·기준일·수집일·라이선스·SHA-256은 `data/source_manifest.json`에 있다.
- `data_sample/` — 가공 데이터 상위 20행 미리보기와 데이터 설명서.
- `result/` — 분석 리포트와 최종 산출물 사본.

## 5. 자주 걸리는 문제

| 증상 | 원인·조치 |
|---|---|
| `node: command not found` | Node.js 20 이상 설치 필요. 3단계 브라우저 엔진 테스트에만 쓰인다 |
| `ModuleNotFoundError: numpy` | 가상환경 활성화 후 `pip install -r requirements.txt` 재실행 |
| `osmium` 설치 실패 | 원본 OSM 재구축에만 필요. `numpy`·`scipy`만 설치해도 `verify_offline.sh`는 통과한다 |
| 대시보드 글꼴이 깨짐 | `docs/fonts/`가 함께 있어야 한다. 폴더째 열 것 |
| `verify_source_lineage.sh` 실패 | 정상. `data/raw/` 원본이 있는 환경에서만 통과한다 |
| Windows에서 `.sh` 실행 불가 | WSL2 또는 Git Bash 사용 |
