# 코드 제출 확인사항 대응표

「[별도 기준] 코드·분석파일 제출 기준」의 확인 항목별 근거다.

| 확인 항목 | 답 | 근거 |
|---|---|---|
| 코드가 실행 가능한 형태로 제출되었습니까? | **예** | `bash verify_offline.sh` 한 줄로 문법·테스트·산출물 재생성·무결성 검증까지 통과. 원본 데이터·API 키 없이 오프라인 실행. 실행 로그는 `docs/verify_offline_log.txt` |
| 실행 방법이 README 또는 실행환경 설명서에 포함되어 있습니까? | **예** | `README.md` 1·2절, `docs/실행환경설명서.md` 전체 |
| 필요한 라이브러리 목록이 포함되어 있습니까? | **예** | `requirements.txt` (osmium 4.3.1, numpy 2.4.6, scipy 1.17.1). Node.js는 내장 `node:test`만 사용 |
| 데이터 경로, 파일명 등이 설명되어 있습니까? | **예** | `README.md` 5절, `docs/실행환경설명서.md` 4절, `docs/DATASETS.md`, `data/source_manifest.json`, `data_sample/데이터_설명서.md` |
| AI 또는 바이브 코딩으로 생성한 코드 범위를 설명하였습니까? | **예** | `docs/AI_USAGE.md`. 줄 단위 생성 이력을 남기지 않았으므로 코드·문서 전체를 AI 보조 범위로 보수적으로 기재 |
| 오픈소스 코드 사용 시 출처와 라이선스를 명시하였습니까? | **예** | `docs/THIRD_PARTY_NOTICES.md`, `docs/DATASETS.md`, `data/source_manifest.json` |

## 제출 형식 대응

| 기준 | 대응 |
|---|---|
| 제출 대상 | 현안 해결 구현 분야 |
| 제출 형식 | 압축파일(`금방_전북금융사각지대진단과찾아가는은행최적동선설계_코드분석파일.zip`) |
| 필수 포함 — 코드 | `src/` 21개 모듈, `tests/`, `config/` |
| 필수 포함 — 실행 설명서 | `README.md`, `docs/실행환경설명서.md` |
| 필수 포함 — 필요 라이브러리 | `requirements.txt` |
| 필수 포함 — 샘플 데이터 또는 데이터 설명 | `data_sample/` (미리보기 + 설명서), `data/processed/` 전량, `docs/DATASETS.md` |
| 파일명 | `팀명_작품명_코드분석파일.zip` 형식 준수 |
| 권장 구성 | `README.md` · `requirements.txt` · `src/` · `data_sample/` · `result/` 모두 존재 |

## 남겨둔 사항

- **팀명·작품명**: [서식 1] 참가신청서 기재값(팀명 `금방`, 작품명 `전북 금융 사각지대 진단과 찾아가는 은행 최적 동선 설계`)에 맞춰 폴더·압축파일 이름을 확정했다.
- **notebook/**: Jupyter 노트북은 두지 않았다. 수집부터 시각화까지 전 과정이 재실행 가능한
  스크립트라 노트북을 별도로 만들 이유가 없었다. 기준표의 "권장 구성"에는 노트북이 없다.
- **data/raw/**: 공개 가능한 원본은 저장소에 포함했다. 재배포 제한 스냅샷(은행연합회·신협·새마을금고)과 카카오 응답 캐시는 비공개 보관하고, `osm.pbf`(285MB)는 Release 자산으로 제공한다.
  재다운로드에 필요한 URL·기준일·SHA-256은 `data/source_manifest.json`에 전부 있다.
